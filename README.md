
# PROJECT AKHIR GRAFIKA KOMPUTER

## Judul
Aplikasi Visualisasi Transformasi Geometri 2D Menggunakan Python dan Tkinter

## Fitur
- Translasi
- Scaling
- Rotasi
- Refleksi
- Shear
- Grid kartesius
- Sistem koordinat tengah
- Tabel koordinat
- Formula panel
- Navigasi 8 arah

## Cara Menjalankan
```bash
python main.py
```

## Teknologi
- Python
- Tkinter

## Konsep Grafika Komputer
Project ini menggunakan:
- Sistem koordinat kartesius
- Matriks transformasi
- Perhitungan manual
- Visualisasi 2D

## Struktur
- core/
- shapes/
- ui/

## Catatan
Semua transformasi dihitung manual tanpa library eksternal.
